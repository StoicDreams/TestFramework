# NuGet Scripts

<webui-page-segment>

List Outdated packages for Solution.

## Solution
<app-files data-trigger="page-solutions" display="[parent]/[file].[ext]" filter="*.sln|*.slnx"></app-files>
<webui-dropdown data-subscribe="page-solutions:setOptions" data-bind="solution"></webui-dropdown>

```PowerShell
$solution = ''
dotnet list $solution package --outdated
```

## Project
<app-files data-trigger="page-projects" display="[parent]/[file].[ext]" filter="*.csproj"></app-files>
<webui-dropdown data-subscribe="page-projects:setOptions" data-bind="project"></webui-dropdown>

Update Package for project

```PowerShell
$project = ''
$packageName = ''
dotnet add $project package $packageName
```

Update all packages in Repo

```PowerShell
Get-ChildItem -Path . -Recurse -Filter "*.csproj" | ForEach-Object {
    dotnet package update --project $_.FullName
}
```
